# Lost Pet Ant Bob!

**Progetto personale | Dicembre 2025**

Lost Pet Ant Bob! è un piccolo progetto web realizzato come scherzo e sorpresa di compleanno per un amico.

Il sito riproduce un volantino per la ricerca di Bob, una formica immaginaria scomparsa, con informazioni divertenti, immagini personalizzate e alcuni elementi interattivi.

L'obiettivo era creare una pagina web originale e stampabile, combinando HTML, CSS e JavaScript.

## Funzionalità

- Visualizzazione di un volantino in formato A4.
- Pulsante animato a forma di formica.
- Riproduzione di un effetto sonoro al clic.
- Apertura della finestra di stampa tramite JavaScript.
- Layout di stampa personalizzato mediante CSS.
- QR code integrato nel volantino.
- Adattamento della pagina a schermi di diverse dimensioni.

## Tecnologie utilizzate

- **HTML5:** struttura della pagina web.
- **CSS3:** personalizzazione grafica, animazioni e layout di stampa.
- **JavaScript:** gestione degli eventi, riproduzione audio e funzionalità di stampa.
- **Bootstrap 5:** organizzazione e impaginazione dei contenuti.

## Avvio del progetto

Il progetto non richiede installazioni o configurazioni particolari.

1. Scaricare il repository.
2. Estrarre i file, se necessario.
3. Aprire `index.html` con un browser.
4. Cliccare sulla formica animata per avviare la stampa del volantino.
